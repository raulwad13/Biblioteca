# Biblioteca 📚

Small browser-based library catalogue exercise. Press the **Mostrar libros** button to render a sample collection of books with their covers, authors, country of origin and Wikipedia links.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- DOM manipulation and JavaScript template literals

## Run locally
Open `index.html` in a browser. Alternatively, start a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure
- `index.html` — page structure and button.
- `style.css` — visual styles.
- `script.js` — sample book data and DOM rendering functions.
- `images/` — book cover images.

## Notes
This is a front-end learning exercise; it does not use a database or backend API.
